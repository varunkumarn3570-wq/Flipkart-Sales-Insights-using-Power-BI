# Flipkart Sales Insights using Power BI

## 📌 Project Overview
This project focuses on analyzing Flipkart sales data to uncover valuable business insights related to sales performance, customer behavior, product categories, and profit trends.  
An interactive Power BI dashboard was created to help visualize and understand the data effectively.

## 🎯 Objectives
- Analyze overall sales performance
- Identify top-performing product categories
- Track monthly sales and profit trends
- Compare regional performance
- Create an interactive business dashboard

## 🛠️ Tools & Technologies Used
- Power BI
- DAX
- Excel / CSV
- Data Cleaning
- Data Visualization

## 📊 Dashboard Features
- Interactive filters and slicers
- KPI Cards for Sales, Profit, and Orders
- Monthly sales trend analysis
- Category-wise performance analysis
- Regional sales comparison
- Profit insights dashboard

## 🔍 Key Insights
- Identified high-performing product categories
- Analyzed monthly sales growth patterns
- Compared profit contribution across regions
- Evaluated customer purchasing trends
